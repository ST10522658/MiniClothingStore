# Dashin Clothing

## ICE Task 2

This project is a mini clothing store application developed as part of ICE Task 2.

The application allows customers to:
- View available stock
- Add products to a shopping cart
- View their cart
- Receive a 10% discount when their cart total is R2999.99 or more
- See how much more they need to spend when they do not qualify
- Checkout their cart

## Discount Functionality

Customers receive a 10% discount when their cart total is R2999.99 or more.

If the cart total is below R2999.99, the application informs the customer how much more they need to spend to qualify for the discount.
